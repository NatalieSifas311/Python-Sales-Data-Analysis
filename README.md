# Python Sales Data Analysis

## Project Overview

This project focuses on analysing retail sales data using Python to identify sales trends, top-performing products, customer purchasing patterns and regional performance.

The analysis demonstrates how Python can transform raw sales data into meaningful business insights.

## Project Objectives

- Explore and understand retail sales data.
- Clean and prepare data for analysis.
- Identify top-performing products and categories.
- Compare sales performance across regions.
- Analyse monthly sales trends.
- Create data visualisations.
- Generate actionable business insights.

## Tools and Technologies

- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

## Dataset Overview

The dataset contains 10 sales records and 9 columns:

- Order ID
- Order Date
- Customer Name
- Product
- Category
- Region
- Quantity
- Unit Price
- Sales

The dataset was checked for missing values and duplicate records.

## Key Findings

1. Sales by Product Category

Category| Total Sales
Computers| 4,500

Computers was the highest-performing product category.

2. Top Performing Product

Laptop – 3,500 in total sales

Laptops generated the highest sales among all products.

3. Sales by Region

Region| Total Sales

Port Moresby recorded the highest regional sales.

4. Monthly Sales Analysis

Month| Total Sales
January| 1,550
February| 355
March| 1,640
April| 780

March recorded the highest monthly sales.

## Business Insights

- Computers contributed the largest share of total sales.
- Laptops were the strongest individual product.
- Port Moresby was the leading sales region.
- March recorded the highest monthly sales.
- Wewak recorded the lowest regional sales, suggesting an opportunity to investigate regional sales performance.

## Conclusion

This project demonstrates practical skills in Python programming, data cleaning, exploratory data analysis and data visualisation.

It highlights how data analysis can help businesses understand sales performance, identify opportunities and make informed decisions.
